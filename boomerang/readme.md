# Boomerang Landing Page

A fully responsive landing page developed as part of the Boomerang theme, featuring a clean and modern design with interactive components, smooth animations, and engaging visual effects.

Bootstrap was used to build the responsive grid, layout structure, navigation, and UI components. jQuery and JavaScript were used to implement interactive features including sliders, tabbed content, and animated counters. The gallery section also features animated hover effects to create a more engaging visual presentation. 

### Features:
✅ Sticky header with responsive navigation.
✅ jQuery-powered intro, testimonial, and partner sliders.
✅ Interactive tabbing functionality.
✅ Animated counting/counter sections.
✅ Gallery section with animated hover effects.
✅ Fully responsive Bootstrap layout.
✅ Built with Bootstrap utility classes.
✅ Clean and semantic HTML structure.
✅ Interactive hover and focus states.
✅ Cross-browser compatible.
✅ Optimized for performance and accessibility.
