# Wedding Advisor Landing Page

A fully responsive landing page developed as part of the Wedding Advisor theme, featuring a clean and modern interface designed to present wedding-related services and content in an engaging and visually appealing way. 

Bootstrap was used to build the responsive grid, layout structure, navigation, and UI components, while jQuery was used to implement the interactive slider.

### Features:
✅ jQuery-powered slider.
✅ Fully responsive layout.
✅ Built with Bootstrap utility classes.
✅ Clean and semantic HTML structure.
✅ Interactive hover and focus states.
✅ Cross-browser compatible.
✅ Optimized for performance and accessibility.
