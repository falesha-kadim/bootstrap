# Splyt Landing Page

A fully responsive landing page for Splyt, a mobility and travel technology platform that integrates ride-hailing, transfers, scooters, bike sharing, and food delivery services into superapps and travel platforms.

The project was built with HTML, Bootstrap, jQuery, and JavaScript, combining a clean, modern interface with smooth animations, interactive elements, and engaging visual effects. The implementation focuses on creating a polished user experience that adapts seamlessly across desktop, tablet, and mobile devices.

Bootstrap was used to build the responsive grid, layout structure, navigation, and UI components. jQuery was used for custom animations and interactive effects, while parallax scrolling and Owl Carousel were incorporated to add visual depth and dynamic content presentation.

### Features:
✅ jQuery-powered animations and interactive effects.
✅ Parallax scrolling effects.
✅ Owl Carousel for responsive content sliders.
✅ Fully responsive layout.
✅ Built with Bootstrap utility classes.
✅ Clean and semantic HTML structure.
✅ Interactive hover and focus states.
✅ Cross-browser compatible.
✅ Optimized for performance and accessibility.
